Curated links to external resources for deeper learning, tools, and communities.

Foundational Papers (External)

Seminal papers that introduced key concepts in AI agents, reasoning, and retrieval.

Agent Foundations

  • ReAct: Synergizing Reasoning and Acting in Language Models (Yao et al., 2022)
    arXiv:2210.03629
    The paper that introduced the ReAct paradigm — interleaving reasoning and acting.

  • Toolformer: Language Models Can Teach Themselves to Use Tools (Schick et al., 2023)
    arXiv:2302.04761
    Foundational work on teaching LLMs to use external tools.

  • HuggingGPT: Solving AI Tasks with ChatGPT and its Friends in Hugging Face (Shen et al., 2023)
    arXiv:2303.17580
    Multi-agent system using specialized models from Hugging Face.

Reasoning Foundations

  • Chain-of-Thought Prompting Elicits Reasoning in Large Language Models (Wei et al., 2022)
    arXiv:2201.11903
    The original Chain-of-Thought paper that started the reasoning revolution.

  • Self-Consistency Improves Chain of Thought Reasoning in Language Models (Wang et al., 2022)
    arXiv:2203.11171
    Introduces self-consistency for improved reasoning accuracy.

  • Tree of Thoughts: Deliberate Problem Solving with Large Language Models (Yao et al., 2023)
    arXiv:2305.10601
    Extends CoT to tree-structured reasoning with backtracking.

Retrieval Foundations

  • Retrieval-Augmented Generation for Knowledge-Intensive NLP Tasks (Lewis et al., 2020)
    arXiv:2005.11401
    The original RAG paper that introduced retrieval-augmented generation.

  • Dense Passage Retrieval for Open-Domain Question Answering (Karpukhin et al., 2020)
    arXiv:2004.04906
    Foundational work on dense retrieval using learned embeddings.

  • HyDE: Precise Zero-Shot Dense Retrieval with Hypothetical Document Embeddings (Gao et al., 2022)
    arXiv:2212.10496
    Query transformation technique for improved retrieval.

Multi-Modal Foundations

  • Learning Transferable Visual Models From Natural Language Supervision (Radford et al., 2021)
    arXiv:2103.00020
    The CLIP paper — foundational for vision-language models.

  • Visual Instruction Tuning (Liu et al., 2023)
    arXiv:2304.08485
    Introduces LLaVA, a foundational vision-language model.

Tools & Frameworks

Open-source tools for building AI agents, RAG systems, and multi-modal applications.

Agent Frameworks

  • LangChain
    Framework for building applications with LLMs, including agents, chains, and tools.

  • LlamaIndex
    Data framework for LLM applications, focused on RAG and data agents.

  • AutoGPT
    Autonomous AI agent that chains GPT-4 calls to accomplish goals.

  • BabyAGI
    Minimal example of an AI-powered task management system.

Retrieval Tools

  • Chroma
    Open-source embedding database for AI applications.

  • Pinecone
    Vector database for production similarity search.

  • Weaviate
    Open-source vector search engine with built-in vectorization.

  • FAISS
    Facebook’s library for efficient similarity search and clustering of dense vectors.

Multi-Modal Tools

  • LLaVA
    Open-source vision-language model.

  • Stable Diffusion
    Open-source text-to-image model.

  • Whisper
    OpenAI’s speech recognition model.
