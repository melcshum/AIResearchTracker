Must-Read Papers

Curated list of influential papers that define key research directions. These papers introduce foundational concepts, reveal important limitations, or open new research areas.

Foundational Papers

Papers that introduce core concepts or paradigms.

PH1

Why it matters: First RL framework that trains GUI agents with world models instead of real environments. Demonstrates that agents can reason about action consequences before committing, enabling predictive planning without expensive real-world interaction.

Key concepts: World Models, Embodied Agents, Planning, Reinforcement Learning

Read if you’re interested in: Agent architecture, GUI automation, model-based RL

PH2

Why it matters: Investigates whether there’s a token-budget threshold below which planning and verification overhead hurts performance. Challenges the assumption that “more thinking = better” and provides practical guidance on when to use structured reasoning.

Key concepts: Token Budget, Chain-of-Thought, Efficiency in Reasoning

Read if you’re interested in: Reasoning efficiency, cost optimization, when to use CoT

PH3

Why it matters: Proposes training-free early exit by probing reasoning stability through adversarial branches. Achieves 30-40% token reduction while preserving accuracy. Immediately deployable for cost reduction.

Key concepts: Early Exit, Adversarial Branch Probing, Efficiency in Reasoning

Read if you’re interested in: Reducing inference costs, reasoning efficiency, practical deployment

Safety & Governance Papers

Papers revealing fundamental safety challenges and proposing governance frameworks.

PH4

Why it matters: Identifies the gap between agent capabilities and judgment. Proposes 4-layer governance at trusted tool boundaries. Essential reading for anyone building production agent systems.

Key concepts: Safety & Governance, Tool Use, Trusted Tool Boundaries

Read if you’re interested in: Agent safety, governance frameworks, production deployment

PH5

Why it matters: Reveals that scaling capabilities creates new attack surfaces. Benign subqueries across independent sessions can be reassembled into forbidden objectives. Larger models paradoxically increase vulnerability — a fundamental scaling law for safety.

Key concepts: Compositional Safety, Intent-Aligned Retrieval, Scaling Laws for Safety

Read if you’re interested in: Agent safety, retrieval security, scaling laws

Efficiency & Optimization Papers

Papers on reducing computational costs while maintaining quality.

PH6

Why it matters: Addresses catastrophic forgetting in multimodal instruction tuning through compact, reusable Mixture-of-Experts with LoRA. Enables sequential task acquisition while preserving previously learned knowledge.

Key concepts: Mixture-of-Experts, Catastrophic Forgetting, Continual Learning

Read if you’re interested in: Efficient multimodal models, continual learning, parameter-efficient tuning

Cross-Modal & Multimodal Papers

Papers advancing models that process multiple modalities.

PH7

Why it matters: Demonstrates multimodal agents for scientific discovery. Combines visual perception, hypothesis generation, and validation for discovering governing PDEs from observational data. Shows how agents can extend beyond language tasks.

Key concepts: Vision-Language Models, Verification, Scientific Discovery

Read if you’re interested in: Multimodal agents, scientific AI, visual reasoning

PH8

Why it matters: Enables native text-vision interaction for multimodal search, ensuring retrieved images remain in context for visually grounded trajectories. Addresses a key limitation of text-only search agents.

Key concepts: Multimodal Search, Vision-Language Models, Tool Use

Read if you’re interested in: Multimodal retrieval, search agents, visual grounding

Domain Application Papers

Papers applying AI concepts to specific domains, revealing practical challenges and solutions.

PH9

Why it matters: Demonstrates that combining LLMs with structured knowledge (knowledge graphs) improves medical reasoning. Shows how hybrid approaches enhance verifiability and explainability in high-stakes domains.

Key concepts: Knowledge Graphs, Hybrid AI, Domain-Specific Reasoning

Read if you’re interested in: Healthcare AI, knowledge graphs, auditable systems

PH10

Why it matters: Addresses the challenge of numerical reasoning over financial documents with tables and charts. Demonstrates retrieval-grounded reasoning for domain-specific QA.

Key concepts: Document Understanding, Retrieval-Augmented Reasoning, Financial AI

Read if you’re interested in: Financial AI, document understanding, numerical reasoning

PH11

Why it matters: Shows that retrieval-augmented approaches improve fallacy detection by providing contextual knowledge beyond surface text. Demonstrates RAG for reasoning about complex, nuanced content.

Key concepts: RAG, Knowledge Graphs, Reasoning with Retrieval

Read if you’re interested in: Political AI, fallacy detection, RAG applications

Evaluation & Benchmark Papers

Papers introducing new benchmarks or revealing limitations in current evaluation.

PH12

Why it matters: Reveals that LLMs rely on surface heuristics rather than genuine counterfactual understanding. Performance collapses under minimal linguistic perturbations, exposing fundamental limitations in causal reasoning.

Key concepts: Causal Reasoning, Evaluation, Robustness

Read if you’re interested in: LLM limitations, causal reasoning, evaluation methodology

PH13

Why it matters: First benchmark to evaluate multimodal AI systems as assistants for users with accessibility requirements. Opens a new research direction at the intersection of multimodal AI and accessibility.

Key concepts: Accessibility, Multimodal Planning, Benchmark Design

Read if you’re interested in: Accessibility AI, multimodal benchmarks, real-world applications

PH14

Why it matters: Large-scale benchmark evaluation reveals that cross-city recommendation methods generalize differently than suggested by smaller benchmarks. Challenges prior conclusions and highlights the importance of scale in evaluation.

Key concepts: Benchmark Design, Cross-Domain Generalization, Retrieval Evaluation

Read if you’re interested in: Recommendation systems, evaluation methodology, generalization
